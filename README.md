# Planchette

MVP statique de recommandation nutritionnelle pour les athlètes. Le formulaire calcule dans le navigateur des repères indicatifs avant, pendant et après l'effort.

## Lancer

Ouvrir `index.html` dans un navigateur. Le projet ne nécessite aucune dépendance ni serveur pour fonctionner.

Les calculs sont des repères généraux et ne remplacent pas l'accompagnement d'un professionnel de santé ou d'un diététicien du sport.
